About Lookamon

A fan-made Pokémon database for exploring and learning about the Pokémon you love.

What is Lookamon?

Lookamon is a browser-based Pokémon encyclopedia. Search for a Pokémon by name or ID, browse the full list, and open any entry to see its types, stats, habitat, and abilities — all in one place.

The project is built with Angular as a learning exercise, with an emphasis on clean, responsive design and a friendly interface that works on phones, tablets, and widescreen desktops.

How to use it

Head to Search if you know what you're looking for — type a name or a Pokédex number into the search bar and pick from the results.

Or visit Explore to browse the full collection at your own pace.
